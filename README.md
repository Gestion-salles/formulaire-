# Gestion des filières (Node.js)

## Lancer le projet
1. Installer Node.js : https://nodejs.org (version LTS)
2. Ouvrir un terminal dans ce dossier
3. Installer les outils : `npm install`
4. Démarrer le serveur : `npm start`
5. Ouvrir http://localhost:3000 dans le navigateur

Les filières enregistrées sont dans `filieres.json`.
Pour les voir : http://localhost:3000/api/filieres
